# Banking System (Python + SQL Server)

## 📁 Project Structure

- db.py → Handles database connection
- auth.py → User authentication (login & registration)
- transactions.py → Deposit, withdraw, transfer logic
- main.py → Entry point and UI (menu-driven program)

---

## 🚀 Features

- User Registration & Login
- Password Hashing (SHA-256)
- Balance Check
- Deposit / Withdraw
- Fund Transfer (with Transactions)
- Transaction History Logging

---

## 🛠 Technologies

- Python
- SQL Server
- pyodbc

---

## 🔐 Security

- Password hashing implemented
- Parameterized queries (SQL injection safe)
- Transaction handling (commit / rollback)
